# yunhee-cli

## 개요

- 상용 agent의 token을 절약하기 위해서 local LLM을 이용하기 위한 Agent

## 프로젝트명 

- 이 프로젝트의 명칭은 `yunhee` 이다.
- `yunhee`란 절약 정신이 투철한 한국여자의 대명사이다.
- claude cli, gemini cli 등 상용 ai agent를 위해서 token을 절약하도록 기반 준비를 한다.


## 목적

- yunhee는 AssetERP(자산운용사용 ERP)의 ASIS 프레임워크(GWT/GXT)를 TOBE 프레임워크(Springboot/React)로 완전히 변환하는 데 필요한 기반작업을 한다.
- yunhee의 작업으로 claude cli, gemini cli등 ai agent는 많은 토큰을 절약하여 변환작업을 수행할 수 있다. 즉 많은 작업을 정해진 token범위 내에서 수행할 수 잇다.


## 실행

run.sh을 작성해 둠.
