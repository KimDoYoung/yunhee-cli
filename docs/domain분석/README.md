# AssetERP 전 도메인 주요 업무 통합 안내서 (Agent Guide)

> **문서 목적**: AI Agent 및 개발자가 AssetERP ASIS 시스템의 43개 비즈니스 도메인 구조를 빠르게 파악하고, 필요한 세부 업무 분석 문서로 직행할 수 있도록 지원하는 **통합 내비게이션 색인**입니다.  
> **포함 정보**: 도메인 약자 및 영문 유래, 한글 업무명, 핵심 역할/기능 요약, 모듈 규모 통계(화면·서버·테이블 수), 상세 분석표 직접 링크.
