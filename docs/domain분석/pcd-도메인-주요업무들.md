# pcd (공용차량 배차 예약) 도메인 주요 업무 리스트 및 분석표

> **문서 목적**: AssetERP의 `pcd` (공용차량 배차 예약) 도메인에 존재하는 주요 업무를 식별하고, 업무 영역별로 체계적으로 분류한 분석 리스트입니다.  
> **분석 대상 소스**: ASIS GXT 소스 (`myApp/client/vi/pcd/*`, `myApp/server/pcd/*`), MyBatis 매퍼 XML, PostgreSQL DB 스키마 (`pcd##_*`), `sys06_menu`.
