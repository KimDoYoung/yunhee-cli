# 수정사항 049 — `screen-capture` 조회 조건 지정·리포트 신호 추가

- 계기: AssetERP **화면 품질 점검**(SID별 대표 화면 캡처) 시험(2026-11-08, yunhee **0.7.6**).
- 재현: `cd AssetERP && yunhee screen-capture 1131 --login kfstest/104/1111 --no-popups`
  - 로그인·겸직 자동 선택(IT본부-전산1팀 / 팀장)·TopBar 열기·[조회] 클릭까지 정상. 5.11초, 2장.
  - 기본 조회 기간(이번 달 2026-10-01~31)에 데이터가 없어 그리드가 **0건**. 정렬·숫자 서식·행 높이 같은 품질 점검을 할 수 없다.
- 시급도: 1번 높음(일괄 캡처의 전제), 2번 중간, 3·4번 중간(이미지 판독 토큰 절감), 5번 낮음.
- 배경 의견: 화면 수백 개를 모두 눈으로 보지 않는다. 텍스트 신호로 먼저 거르고 의심 화면만 이미지로 연다(이미지 1장 ≈ 1,200~1,900 토큰). 로컬 모델은 이미지를 못 읽으므로 yunhee는 신호 수집을 맡는다.

---

## 1. `--range` 옵션 (우선순위 높음)

- 형식: `--range 2025-01-01~2026-12-31`
- 동작: 조회 줄(SearchBar)에서 날짜 범위 입력(시작일·종료일 두 칸)을 **모두** 찾아 이 범위로 채운 뒤 [조회]를 누른다.
- 라벨명을 쓰지 않으므로 SID별 일괄 캡처에 맞다.
- 날짜 칸이 여러 쌍이면 모두 같은 범위로 채운다. 날짜 칸이 없는 화면은 무시하고 리포트에 "날짜 범위 없음"으로 적는다.
- AntD DatePicker는 타이핑 후 Enter로 입력하고, 달력 팝업이 남으면 Esc로 닫는다.

## 2. `--set` 옵션 (반복 가능)

- 형식: `--set 승인기간=2025-01-01~2025-12-31 --set 상태=승인 --set 검색=삼성`
- 대상: **조회 줄(SearchBar) 안의 입력만**. 편집 폼·모달의 필드는 건드리지 않는다(같은 라벨 중복 문제를 줄인다).
- 위젯 유형은 자동 판별한다.

| 위젯 | 값 |
|:---|:---|
| 텍스트 | 입력할 문자열 |
| 날짜 | `YYYY-MM-DD` |
| 날짜 범위 | `YYYY-MM-DD~YYYY-MM-DD` |
| Select(드롭다운) | 옵션 글자 일치 |
| 체크박스 | `true`/`false` |
| 조회창 필드 | 미지원 — 리포트에 "미지원"으로 적는다 |

- 같은 라벨이 여럿이면 `라벨#2`로 두 번째를 지정한다.
- `--range`와 함께 주면 `--set`이 우선한다.
- 라벨이 입력칸과 연결(`for`/`id`)되지 않은 인라인 텍스트일 수 있다(1131 "승인기간"이 그렇게 보임). 라벨 텍스트 옆 입력 요소를 찾는 방식이 필요하다.

## 3. 라벨을 못 찾았을 때

- 실패로 끝내지 말고 조회 줄의 라벨 목록을 출력한다.
  예: `라벨 '승인기간' 못 찾음. 조회 줄 후보: 승인기간, 검색, ...`
- 캡처는 계속 진행하고(기본값으로 조회) 리포트에 경고로 남긴다.

## 4. 리포트(`--json`·텍스트)에 텍스트 신호 추가

화면별로 다음을 남긴다. 이상 신호가 있는 화면만 이미지를 열기 위함이다.

- 콘솔 에러, 실패한 네트워크 호출(4xx/5xx) 건수와 첫 몇 건.
- 그리드별: 행 수, 헤더 줄바꿈(두 줄로 잘린 헤더. 1131 "인당 경제적가치"가 예) 여부, 빈 그리드 여부.
- 버튼 목록과 비활성 여부.
- 가로 스크롤 발생 여부.
- 팝업 순회: 클릭한 버튼, 열린 모달 유무, 클릭했으나 안 열린 버튼과 추정 사유(행 선택 필요 등).
- 적용된 조회 조건(`--range`/`--set`), 겸직 선택 결과.

## 5. 기타

- 뷰포트 기본값(1920×1080)은 토큰을 줄이려고 1280×720 또는 1440×810으로 쉽게 고를 수 있으면 좋다(`--viewport`는 이미 있음, 기본값만 논의).
- 팝업은 모달 영역(`.ant-modal`)만 잘라 저장하는 `--modal-only`가 있으면 이미지가 작아진다.
- 위험 버튼(저장·삭제·승인 등)은 기본으로 클릭하지 않는다. **현재 팝업 순회가 이런 버튼도 누르는지 확인 요청.** 기본 제외가 아니면 `--click-all`로 선택하게 바꾼다.

## 확인 요청 (AssetERP 쪽에서 확인하지 못한 것)

- 현재 팝업 순회가 저장·삭제 같은 버튼도 누르는지.
- 조회 줄에서 날짜 칸을 찾는 방식(DOM)이 `SearchBar` 부품과 일반 `Form` 모두에 통하는지.

## 첫 시험 방법

1. `yunhee sql`로 1131(`Biz01_Tab_Card`)의 데이터가 있는 기간을 확인한다.
2. `yunhee screen-capture 1131 --login kfstest/104/1111 --range <그 기간>`으로 그리드에 행이 채워지는지 본다.
3. 되면 SID별 대표 화면(page-style 견본, 모달 견본 MF·MG·MFG·MH의 부모 화면) 일괄 캡처로 넘어간다.
