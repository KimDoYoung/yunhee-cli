# 수정사항 057 — `screen-capture --boxes`: 캡처 이미지에 보이는 요소의 좌표 파일(`*.boxes.json`) 함께 저장

- 계기: framework-sprt에 6번째 작업 "매뉴얼"(TOBE 화면을 A-Man 매뉴얼로 자동 제작)을 추가하려 한다. 매뉴얼 이미지에는 버튼·행·팝업에
  **번호 배지·빨간 사각형·화살표**를 그려 넣어야 한다. 그리는 일은 `yunhee mark`(수정사항058)가 하고,
  **무엇이 어디에 있는지**는 캡처하는 순간 브라우저(DOM)가 가장 정확히 안다. 그 좌표를 캡처와 함께 내 달라는 요청이다.
- 시급도: 중간(없으면 좌표를 이미지를 보고 사람이 짚어야 해 오차가 나고 자동화가 막힌다. 그동안은 좌표 직접 지정으로 시험할 수 있다).
- 상세 규격: **`docs/boxes-json-규격.md`** (이 문서는 요청 요약, 형식·이름 규칙·예시는 그 문서를 따른다).
- 재현/확인은 `cd ~/work/framework-sprt/AssetERP`에서. 예: `yunhee screen-capture 1412 --login kfstest/121/1111 --boxes`.

---

## 1. 요청 요약

`yunhee screen-capture`에 **`--boxes`** 옵션을 더한다.

- 켜면 PNG마다 **같은 이름의 `.boxes.json`**(예: `01_initial.boxes.json`)을 같은 폴더에 만든다. 기본은 꺼짐.
- 파일에는 그 PNG에 **보이는** 요소의 `name`·`kind`·`box([x,y,w,h], PNG 픽셀 기준)`·`area`(main/modal/lookup) 등을 담는다.
- `report.json`의 캡처 목록 항목에 `boxes` 키로 파일 이름을 적는다.

## 2. 꼭 지켜야 할 것 (규격서 3·5절)

| 항목 | 요구 |
|:---|:---|
| 좌표 기준 | **PNG 이미지 기준 픽셀.** `box = ((rect.x − origin.x) × scale, (rect.y − origin.y) × scale, rect.w × scale, rect.h × scale)`. 변환은 yunhee가 하고 `mark`는 그대로 쓴다. |
| `--modal-only` | 잘라낸 모달 영역의 왼쪽 위를 `origin`으로 저장하고 그만큼 빼서 기록. |
| 보이는 것만 | `display:none`·크기 0·다른 탭·가려져 PNG에 안 보이는 요소는 뺀다. 이미지 밖으로 걸치면 이미지 영역으로 자른다. |
| 이름 | 화면에 보이는 글자를 그대로. 같은 이름이면 DOM 순서로 `이름#2`, `#3`. 그리드는 `grid1.행2.수정`, 모달 제목은 `책무:제목`. |
| 시점 | 팝업이 열린 시점·탭이 바뀐 시점마다 그 순간의 DOM에서 따로 수집(PNG 한 장당 JSON 한 개). |
| 수집 방법 | 요소마다 `bounding_box()`를 부르지 말고 `page.evaluate` 한 번으로 모아서 반환(느려진다). |

## 3. 처음 구현 범위

규격서 6절의 최소 범위: button · icon-button · input · select · date · checkbox · label · tab · grid · grid-header · grid-row · grid-cell · grid-icon · grid-check · modal · modal-title.
나머지(toolbar, search-bar, radio …)는 필요할 때 더한다. 그리드 행·셀은 기본 행 20개·셀은 헤더·첫 5행·아이콘·체크박스만(규격서 7절).

## 4. 수용 기준(이렇게 되면 끝)

1. `yunhee screen-capture 1412 --login kfstest/121/1111 --boxes`가 PNG와 `.boxes.json` 쌍을 만든다(`--boxes` 없이는 JSON을 만들지 않는다).
2. `box`로 PNG 위에 빨간 사각형을 그리면 **버튼·팝업·그리드 행에 정확히 겹친다**(전체 캡처와 `--modal-only` 모두). yunhee 테스트에 이 겹침 검사를 둔다(규격서 9절).
3. 같은 이름의 요소가 `#2`로 구분되고, 파일 안에서 `name`이 중복되지 않는다.
4. `--viewport 1440x810`처럼 뷰포트를 바꿔도 `image-size`·`viewport`·`scale`이 실제와 맞는다.
5. 버전을 올리고 `changelog`에 줄을 남긴다(수정사항056 §2).

## 5. 열린 질문 (구현하며 정해 주세요, 규격서 10절과 같다)

- 폼 라벨을 입력칸 `name`으로 삼을 때 AntD `Form.Item` 라벨을 어디까지 따라갈지.
- 헤더 글자 없는 아이콘 컬럼(수정·삭제 아이콘)의 `col` 이름.
- `--modal-only`의 `origin`에 모달 padding을 포함할지.
- boxes.json 용량(장당 수십 KB 이하 예상).

## 6. 이 요청과 이어지는 것 (참고, yunhee 작업 아님)

- `yunhee mark <png> <draw.json> --out <png>`(**수정사항058**): `draw.json`의 `"target": "등록"`을 `boxes.json`에서 찾아 그린다.
  `screen-capture`는 그리지 않고 좌표만 낸다. 규격서 11절 참조.
- framework-sprt `AssetERP/docs/6-매뉴얼/`(작성 예정)이 이 둘을 쓴다.
