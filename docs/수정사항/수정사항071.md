바라는 것:

1. 이름은 **JSX 속성 값(글자 상수)에서만** 가져온다: `label="…"`, `placeholder="…"`, `title="…"`, 버튼 자식 글자, 그리드 열 제목(`gb.*`의 header 인자). 주석(`//`, `/* */`, `{/* */}`, JSDoc)은 이름 출처로 쓰지 않는다.
2. label이 없는 입력 요소는 **위치로** 가리킨다. 예: `{ do: "selectEach", in: "SearchBar", index: 1, src: "…:111" }`(SearchBar 안에서 0부터 센 입력 요소 순서). id는 `Dcr10_Tab_MailHistory/selectEach:#1` 처럼 위치 기반. 위치도 정하기 어려우면 `unknown`.
3. 모달 제목이 글자 상수가 아니면(`title={변수}`, JSX, 템플릿 문자열) `expectModal: true`(아무 모달이나 열리면 통과)로 쓴다. 상수 후보(`?? '문서상세'`)를 쓰지 않는다 — 실제로는 앞 값이 대부분이다.
