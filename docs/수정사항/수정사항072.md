# 수정사항 072 — `test-gen-screen`(1.0.3): mayWarn이 error에도 붙음, index 세는 규칙, Space 대신 보이는 글자

- 계기: 수정사항071을 반영한 1.0.3을 framework-sprt 5개 화면(1023·1049·1378·1077·1282)으로 다시 검수했다(2026-11-17). 071의 문제는 모두 고쳐졌고 아래 3건이 남았다.
- **이 수정은 Claude(framework-sprt 세션)가 직접 했다**(사용자 요청, 1.0.4). 고치기 전에 Gemini 작업분(1.0.2·1.0.3)을 `06699ea`로 먼저 커밋해 두었다.

## 1. `mayWarn`이 `message.error`에도 붙는다 (중요)

- 1049 `Fnd01_Tab_FundSearch/click:엑셀다운로드`에 `mayWarn: true` — 근거는 `Fnd01_Tab_FundSearch.tsx:80` `message.error(errorMessage(err, '다운로드 실패'))`. 1077 `click:새로고침`도 `Sys06_Tab_Menu.tsx:64`의 `message.error`.
- 실행기는 `mayWarn`을 "모달 대신 메시지가 떠도 PASS"로 보므로 **실제 실패가 PASS로 덮인다.** 071 3절에 `error`까지 넣어 쓴 것이 원인.
- 고침: `_handler_may_warn`은 `message.warning|info`·`Modal.warning|info`만 본다.

## 2. `index` 세는 규칙

- 1023 SearchBar = [발신일자 Field(DatePicker 2개)] [Select] [연관펀드 Field] [검색 Field] → Select가 `index: 1`. 즉 Field 하나를 1칸으로 센다. 화면의 input 요소 단위로 세면 2가 되므로 실행기와 규칙이 같아야 한다.
- 고침(규칙은 그대로, 문서화): Field 계열(`SearchBar.Field`·`SearchPanel.Field`·`EditField`·`Form.Item`) 하나 = 1칸, Field 밖 입력 요소 하나 = 1칸, 버튼·글자는 안 셈. `index` 단계가 있는 `.gen.cjs` 머리에 이 규칙을 한 줄 주석으로 적는다.

## 3. `in: "Space"` 대신 앞에 보이는 글자

- 1077 `Sys01_Grid_CompanyMenu.tsx:98-101`: `<Space wrap><Typography.Text strong>적용상품</Typography.Text>{/* 주석 */}<SystemCodeComboBox …/>` → 1.0.3은 `selectEach:#0`, `in: "Space"`. `Space`는 화면에 여럿일 수 있어 범위가 넓다.
- 고침: 속성 label이 없으면, 컨트롤 **바로 앞**에 화면에 그려지는 글자 태그(`Typography.Text`·`Text`·`span`·`label`·`b`·`strong`)가 있을 때 그 글자를 label로 쓴다(사이에는 공백·주석 자리 `{ }`만 허용). 주석은 여전히 쓰지 않는다. → `selectEach:적용상품`.
