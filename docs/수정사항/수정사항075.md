## A. 대장과 같은 폴더의 `보관/*.md`도 읽는다

### 지금
`src/yunhee/tools/as_is/drift.py` L1849-1878. `resolve_ledger_path(wd)`가 돌려준 파일 **하나**(`docs/3-변경반영/변경반영-대장.md`)만 읽어서 `done_shared_units`를 채운다.

framework-sprt는 끝난 줄(`반영`·`해당없음`)을 `docs/3-변경반영/보관/2026-11.md`로 옮긴다(지금 449줄). 그래서 판단 기록 대부분을 drift가 못 본다.

### 고칠 것
1. L1849 `l_path = resolve_ledger_path(wd)` 바로 아래에서 읽을 파일 목록을 만든다.
   ```python
   ledger_files = [l_path] if l_path.is_file() else []
   arc_dir = l_path.parent / "보관"
   if arc_dir.is_dir():
       ledger_files += sorted(arc_dir.glob("*.md"))
   ```
2. L1850 `if l_path.is_file():` 블록(L1850-1878)을 `for lf in ledger_files:` 반복으로 바꾼다. 안의 내용은 **그대로**이고, `l_path.read_text(...)`만 `lf.read_text(...)`로 바꾼다.
   - 파일마다 `parse_ledger_header`를 따로 부른다. 머리줄 위치가 파일마다 다르다(대장 L33, 보관 L30). 머리줄은 같다: `| 키 | 발견일 | AS-IS 커밋 | 종류 | 단위 | 변경 요약 | 영향 화면 | TOBE 대응 | 확인 | 상태 | 처리일 | 비고 |`.
   - 머리줄을 못 찾은 파일(`h_idx == -1`)은 건너뛴다.
3. 다른 곳은 고치지 않는다. `resolve_ledger_path` 함수도 그대로 둔다.

## B. import·package·빈 줄·주석만 있는 hunk는 단위 판정에서 뺀다

### 지금
`drift.py` `_changed_units_for_file` L1502-1519. hunk 하나라도 메서드·SQL 범위 밖이면 `None`을 돌려준다("모르면 보고"). 그러면 L2117 `if changed_units:`가 거짓이 되어 제외하지 않는다.

실제 예: 원본 `ad36c5e64`의 `Apr01_Appr.java` hunk 4개 중 3개가 import다(`@@ -3,0 +4,2`·`@@ -4,0 +7`·`@@ -28 +30,0`). 바뀐 메서드 `update`는 대장 CH-0475에서 판단을 끝냈는데도, import 때문에 `update`를 안 쓰는 화면에까지 계속 보고된다.

### 고칠 것
1. `drift.py`에 함수 하나를 더한다(`_changed_units_for_file` 바로 위).
   ```python
   _NEUTRAL_RE = re.compile(
       r"^(import\s|package\s|//|/\*|\*|\*/|<!--|-->)"
   )

   def _is_neutral_hunk(h: dict[str, Any]) -> bool:
       """바뀐 줄(+/-)이 모두 import·package·빈 줄·주석이면 True."""
       changed = [ln[1:] for ln in h.get("lines", []) if ln[:1] in ("+", "-")]
       if not changed:
           return True
       for body in changed:
           s = body.strip()
           if s == "" or _NEUTRAL_RE.match(s) or s.endswith("-->"):
               continue
           return False
       return True
   ```
   - `h["lines"]`는 `drift_ops.parse_diff_hunks`(drift_ops.py L289-299)가 이미 채운다. `+`·`-`·` `로 시작하는 원래 줄이다.
2. `_changed_units_for_file`의 L1502 `for h in hunks:` 반복 맨 앞에 두 줄을 넣는다.
   ```python
   for h in hunks:
       if _is_neutral_hunk(h):
           continue
       h_matched = False
       ...
   ```
3. L1521 `result = sorted(matched) if matched else None`은 **그대로** 둔다. hunk가 모두 neutral이면 `None`이 되어 지금처럼 보고된다. import만 바뀐 파일도 보고되는 쪽(안전한 쪽)을 유지한다.
4. 다른 곳은 고치지 않는다. 특히 L2136 "이 화면이 그 단위를 쓰면 제외 금지"는 그대로다. `update`를 실제로 쓰는 화면(결재 문서창으로 상신하는 화면)에는 계속 뜨는 것이 맞다(063 설계).
