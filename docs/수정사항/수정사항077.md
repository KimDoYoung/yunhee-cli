# 수정사항 077 — `kbd --check --fix`가 `아이콘없음` 버튼의 md 아이콘을 지움

- 계기: framework-sprt 세션에서 수정사항076(yunhee 1.1.2) 구현을 시험하다 발견(2026-11-24).
- 작성: Claude(framework-sprt 세션), 사용자 요청.
- 관련: 수정사항076 B(판정 `아이콘없음`)·C(`--check`/`--fix`).

---

## 1. 문제

캡처한 버튼의 anticon이 변환표(076 "Ant Design → FontAwesome 표")에 없으면 B는 `fa = null`로 보고 표기를 `` `색::글자` ``(아이콘 빈 칸)로 만든다(`src/yunhee/tools/kbd.py` L415-419). 이건 "사람이 아이콘을 채워라"라는 뜻의 **불완전한 표기**다.

그런데 C(`--check`)는 이 불완전한 표기를 "정답"으로 다룬다(L738-755). md에 사람이 아이콘을 채워 넣은 올바른 표기가 있어도 `❌`가 되고, `--fix`가 그 아이콘을 지운다.

### 재현 (framework-sprt, #1007 캡처의 사본)

boxes.json에서 `상세 보기` 모달의 `수정` 버튼 `style.icon`을 `anticon-foo`로, `style.fa`를 `null`로 바꾼 뒤:

```bash
yunhee kbd <boxes폴더> --defines defines.json
# | 수정 | 상세 보기 | 6AB6CF - | 6AB6CF edit | 아이콘없음 ⚠anticon-foo | `6AB6CF::수정` ⚠anticon-foo |

yunhee kbd --check good.md --defines defines.json --boxes <boxes폴더>
# ❌ L5 `6AB6CF:eye:수정` → `6AB6CF::수정`
# 종료코드 1
```

이 상태에서 `--fix`를 돌리면 md의 `` `6AB6CF:eye:수정` ``이 `` `6AB6CF::수정` ``으로 바뀐다. 그러면 A-Man에서 아이콘이 없어진다.

시험 파일은 framework-sprt 세션 scratchpad에 있다(`fx/good.md`, `fx/defines.json`, `fx/boxes2/`). 휘발성이라 위 설명만으로 재현할 수 있게 적었다.

---

## 2. 고칠 것

`--check`에서 맞춰 본 행(`matched_rows`)의 판정이 `아이콘없음`이면 **❌로 보지 않고 ⚠로 알린다. `--fix`는 고치지 않는다.**

| md 표기 | 보고 |
|:---|:---|
| `` `색:아이콘:글자` ``이고 색 = TOBE `bg` | `⚠ L5 \`6AB6CF:eye:수정\` — 아이콘 확인(TOBE anticon-foo, 변환표에 없음)` |
| `` `색:아이콘:글자` ``이고 색 ≠ TOBE `bg` | `⚠ L5 \`123456:eye:수정\` — 아이콘 확인(TOBE anticon-foo, 변환표에 없음) · 색은 6AB6CF` |
| `` `글자` ``만 있음, 또는 `` `색::글자` `` | `⚠ L5 \`수정\` — 아이콘 확인(TOBE 6AB6CF anticon-foo, 변환표에 없음)` |

- 세 경우 모두 `--fix`로 바꾸지 않는다. 색만 틀린 경우도 사람이 아이콘과 함께 보도록 그대로 둔다.
- 요약 줄에 따로 센다: `… · 아이콘 확인 1`. 고칠 것(❌)이 아니므로 **종료코드에 영향 없음**(다른 ⚠와 같음).
- 창마다 다름(L722-736)을 먼저 판정하는 순서는 그대로 둔다.
- `--json` 출력이 있으면 `status: "icon-unknown"`으로 둔다.

### 바꾸지 않는 것
- B(`yunhee kbd`)의 `아이콘없음` 판정과 표기 `` `색::글자` `` + `⚠anticon-xxx` — 그대로(표를 보는 사람에게는 맞는 정보다).
- 변환표, `YUNHEE_KBD_ICON_MAP`, 다른 판정의 ❌/`--fix` 동작.

---

## 3. 확인 방법

1. 위 재현 그대로 `--check` → `❌` 대신 `⚠ … 아이콘 확인`, 요약에 `아이콘 확인 1`, 종료코드 0.
2. 같은 md로 `--fix` → 파일이 바뀌지 않는다(`수정`이 `` `6AB6CF:eye:수정` ``으로 남음). 고칠 것이 0이면 `.bak`도 만들지 않는다.
3. 같은 md에 `` `저장` ``(글자만)을 섞어 `--fix` → `저장`만 `` `0F7F90:check:저장` ``으로 고치고 `수정`은 그대로.
4. 아이콘이 정상인 #1007 캡처(사본 아님)로 076 확인 항목을 다시 돌려도 결과가 같다(회귀 없음).
5. `tests/test_kbd.py`에 위 1~3 경우를 넣는다.
