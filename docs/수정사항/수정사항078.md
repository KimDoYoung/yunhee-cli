# 수정사항 078 — `yunhee kbd` 표: `아이콘없음`의 `⚠anticon-xxx`가 판정·표기 두 칸에 겹쳐 나옴

- 계기: framework-sprt 세션에서 수정사항076·077(yunhee 1.1.2·1.1.3)을 시험하다 발견(2026-11-24). 076 시험 보고의 "고칠 점 2번".
- 작성: Claude(framework-sprt 세션), 사용자 요청.
- 대상: `yunhee kbd <boxes>`의 **md 표 출력만** 고친다(`render_kbd_markdown`). `--json`·`--check`·`--fix`는 바꾸지 않는다.
- 줄 번호는 yunhee 1.1.3 working tree의 `src/yunhee/tools/kbd.py` 기준이다(커밋 전이라 조금 다를 수 있다).

## 1. 지금 모습

변환표에 없는 anticon을 쓰는 버튼(판정 `아이콘없음`)은 `⚠anticon-xxx` 같은 내용이 **판정 칸과 표기 칸에 두 번** 나온다.

```
| 버튼 | 창 | TOBE | A-Man | 판정 | 표기 |
| 수정 | 상세 보기 | 6AB6CF - | 6AB6CF edit | 아이콘없음 ⚠anticon-foo | `6AB6CF::수정` ⚠anticon-foo |
```

### 원인 — 같은 `note`를 두 곳에서 붙인다
1. `_judge_button` L415-419: `fa is None`이면 `note = f"⚠{btn.icon}"`.
2. 같은 함수 L439-444: `verdict_display`를 만들 때 `note`가 있으면 `f"{verdict} {note}"`. → **판정 칸**에 붙음.
3. `render_kbd_markdown` L559-560: `verdict == "아이콘없음"`이고 `note`가 있으면 `notation_cell`에 `note`를 또 붙임. → **표기 칸**에 붙음.

### 같은 원인에서 나오는 앞뒤가 안 맞는 경우
버튼이 꺼진 것만 캡처되면(`disabled_only`) L440이 먼저라서 판정 칸에는 `⚠꺼짐`만 나오고, 표기 칸에만 `⚠anticon-foo`가 나온다.
```
| 수정 | 상세 보기 | 6AB6CF - | 6AB6CF edit | 아이콘없음 ⚠꺼짐 | `6AB6CF::수정` ⚠anticon-foo |
```
`note`가 판정 칸에 붙기도 하고 안 붙기도 해서 사람이 헷갈린다.

## 2. 고칠 것 — `⚠anticon-xxx`는 표기 칸에만 둔다

수정사항076 B-3 판정표의 정의(`아이콘없음` 표기 = `` `색::글자` `` + `⚠anticon-xxx`)를 따른다. 표기 칸은 사람이 md에 옮겨 적을 때 보는 칸이라, 무엇을 채워야 하는지가 거기 있어야 한다.

1. **판정 칸**(`verdict_display`)에는 `note`를 붙이지 않는다. 판정 칸에 붙는 것은 `⚠꺼짐` 하나뿐이다.
   - 바꾸기 전(L439-444):
     ```python
     if btn.disabled_only:
         verdict_display = f"{verdict} ⚠꺼짐"
     elif note:
         verdict_display = f"{verdict} {note}"
     else:
         verdict_display = verdict
     ```
   - 바꾼 뒤(뜻):
     ```python
     verdict_display = f"{verdict} ⚠꺼짐" if btn.disabled_only else verdict
     ```
2. **표기 칸**은 지금처럼 `render_kbd_markdown` L559-560에서 `note`를 붙인다(그대로).
3. `--json`의 `verdict`·`notation`·`note` 키와 값은 그대로 둔다. `verdict_display`가 JSON에 나가지 않는다면 JSON 출력은 한 글자도 바뀌지 않아야 한다.

### 고친 뒤 모습
```
| 수정 | 상세 보기 | 6AB6CF - | 6AB6CF edit | 아이콘없음 | `6AB6CF::수정` ⚠anticon-foo |
| 수정 | 상세 보기 | 6AB6CF - | 6AB6CF edit | 아이콘없음 ⚠꺼짐 | `6AB6CF::수정` ⚠anticon-foo |   ← 꺼진 것만 캡처된 경우
```
- `⚠anticon-foo`는 한 줄에 **딱 한 번**, 표기 칸에만 나온다.
- 다른 판정(`같음`·`색다름`·`아이콘다름`·`둘다다름`·`A-Man없음`)의 줄은 바뀌지 않는다(`note`가 없으므로).

### 바꾸지 않는 것
- `--check`/`--fix`의 메시지(077의 `⚠ … 아이콘 확인(TOBE anticon-foo, 변환표에 없음)`)와 판정·종료코드.
- `--json` 출력.
- 표의 열 순서·제목 줄(`### 버튼 표기 (…)`).

## 3. 검증 방법

### 시험 자료 만들기
정상 캡처(#1007)의 boxes.json 사본에서 버튼 하나의 아이콘을 변환표에 없는 것으로 바꾼다.

```bash
cd ~/work/framework-sprt/AssetERP
yunhee screen-capture 1007 --login kfstest/121/1111 --boxes -o /tmp/kbd078
B=/tmp/kbd078/1007_Dcr05_Tab_DocType
cp -r $B /tmp/kbd078/icon  && cp -r $B /tmp/kbd078/icon-off
f=05_popup_03_상세_보기.boxes.json
# (가) 수정 버튼 아이콘을 변환표에 없는 것으로
jq '(.elements // .) |= map(if .text=="수정" then .style.icon="anticon-foo" | .style.fa=null else . end)' $B/$f > /tmp/kbd078/icon/$f
# (나) (가) + 꺼진 것만 캡처된 상태
jq '(.elements // .) |= map(if .text=="수정" then .style.icon="anticon-foo" | .style.fa=null | .disabled=true else . end)' $B/$f > /tmp/kbd078/icon-off/$f
```
A-Man 서버가 없으면 `--defines`로 시험용 정의 파일을 준다. 최소로 `{"color":"6AB6CF","icon":"fas fa-edit","texts":["수정"]}`이 들어 있으면 된다.

### 단위 테스트 (`tests/test_kbd.py`)
- `render_kbd_markdown` 결과에서 `아이콘없음` 줄을 골라 `|`로 나눈 칸을 본다.
  - 판정 칸 == `아이콘없음` (꺼짐이면 `아이콘없음 ⚠꺼짐`)
  - 표기 칸이 `⚠anticon-foo`로 끝남
  - 줄 전체에 `anticon-foo`가 1번만 나옴
- 위 두 경우(켜짐·꺼짐 only)를 각각 넣는다.
- 기존 테스트 중 판정 칸에 `⚠anticon-…`이 있다고 기대하는 것이 있으면 새 기대로 고친다.
