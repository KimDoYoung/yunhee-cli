## 평가1

  ### 2. 사용자가 직접 테스트해보는 방법

  사용자가 대화형으로 모델의 도구 호출 및 파일 작업을 직접 검증해볼 수 있도록 전용 대화형 테스트 스크립트 test_agent.py를
  준비했습니다.

  #### 실행 명령어

    uv run examples/test_agent.py

  #### 추천 테스트 시나리오

  터미널 프롬프트(you>)가 뜨면 아래 질문들을 입력해 보세요:

  1. 파일 목록 및 폴더 탐색 테스트:
    you> docs 폴더 안에 어떤 파일들이 있는지 확인해줘.

      • 모델이 list_files(directory='docs')를 자율적으로 호출하고 결과를 한국어로 요약해줍니다.
  2. 파일 내용 읽기 테스트:
    you> pyproject.toml 파일 내용을 읽어서 어떤 라이브러리가 설치되어 있는지 알려줘.

      • 모델이 read_file(filename='pyproject.toml')을 호출하여 의존성을 분석해줍니다.
  3. 다단계 자율 작업 테스트 (파일 쓰기 후 읽어서 검증):
    you> .yunhee/my_test.txt 파일에 "하네스 1단계 검증 완료!"라고 적고, 잘 저장되었는지 다시 확인해줘.

      • 모델이 write_file을 실행한 다음, 스스로 read_file을 연계 호출하여 파일 내용을 확인하고 최종 답변을 작성합니다.
  4. 단위 테스트 재검증 (CLI):
    uv run pytest tests/test_agent_*.py



  ### 추가된 2가지 도구 상세

  #### 1. find_files (파일명 재귀 고속 검색)

  • 역할: 하위 폴더 깊숙한 곳까지 이름 패턴(glob)에 일치하는 파일들을 한 번에 재귀 검색합니다.
  • 안전 가드: .git, .venv, target, node_modules, __pycache__ 등 불필요한 대용량 캐시/빌드 폴더는 **자동 제외(ignore)**하여
  속도와 토큰을 절약합니다.

  #### 2. grep_search (텍스트/코드 고속 핀포인트 검색)

  • 역할: 수많은 파일 중에서 특정 키워드나 정규식이 일치하는 파일 경로, 줄 번호, 실제 코드 라인을 1초 만에 추출합니다.
  • 안전 가드: 이미지나 바이너리 파일 자동 감지 스킵, UTF-8 및 CP949 인코딩 자동 호환.

  ### 바로 테스트하기

  uv run examples/test_agent.py 실행 상태에서 다음과 같이 질문해 보세요:

  1. find_files 테스트 (파일명 검색):
    you> docs 폴더 아래에 있는 모든 .md 파일들을 찾아줘.

      • 모델이 find_files(directory='docs', pattern='*.md')를 호출하여 깊은 하위 폴더의 모든 마크다운 파일 목록과 용량을 한 번에
      가져옵니다.
  2. grep_search 테스트 (코드/문구 검색):
    you> class AgentLoop 가 선언된 파일과 줄 번호를 찾아줘.

      • 모델이 grep_search(query='class AgentLoop')를 호출하여 정확히 src/yunhee/agent/loop.py:30을 핀포인트로 찾아내어 답변해
      줍니다.
